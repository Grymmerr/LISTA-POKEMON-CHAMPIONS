POKÉMON CHAMPIONS TRACKER — PWA

Contenido:
- index.html: aplicación
- manifest.json: configuración de instalación como app
- sw.js: caché/offline
- icons/: iconos de la aplicación

Para publicarla:
1. Sube TODOS estos archivos a la raíz de un repositorio de GitHub Pages.
2. Activa Settings > Pages > Deploy from a branch > main > /(root).
3. Abre la URL publicada desde Chrome en Android.
4. Chrome debería ofrecer Instalar aplicación / Añadir a pantalla de inicio.
